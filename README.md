# TEXT CLASSIFICATION BATTLE
## Airline Sentiment Analysis Using Machine Learning

### Project Overview
This project compares four machine learning algorithms
for classifying airline customer tweets into sentiment
categories.

### Dataset
Twitter Airline Sentiment Dataset

Kaggle Source:
https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment

### Sentiment Classes
1. Positive
2. Negative
3. Neutral

### Algorithms Used
1. Decision Tree
2. K-Nearest Neighbours (KNN)
3. Support Vector Machine (SVM)
4. Naive Bayes

### Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
- Seaborn

### Text Preprocessing
- Lowercase conversion
- URL removal
- Username removal
- Stop-word removal
- Stemming
- TF-IDF feature extraction

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Training and Testing Time

### Experimental Setup
Training data: 80%
Testing data: 20%

### What-if Analysis
The KNN algorithm is tested with different
neighbour values to study the effect of K
on classification performance.

### Conclusion
The four classifiers are compared using the
same dataset and evaluation procedure.
The most suitable classifier is selected
based on the experimental results.
